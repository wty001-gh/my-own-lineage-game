# Grok library imports

Place images downloaded from grok.com Library here.

- Game-relative path: `assets/portraits/grok-library/<filename>`
- To wire a hero: set `portraitId: 'grok:<filename>'` in `js/60-heroes.js` (HERO_DB)
- Do not put v8 portraits here — those stay in the parent `assets/portraits/` folder as `v8-*.webp`
