# 武器附魔設計（席琳・克洛托）

日期：2026-09-17（Asia/Taipei）・修訂 b  
範圍：**僅武器**（防具／飾品附魔暫留 stub，稍後再開）

## 設計原則

1. **先抽後升**：克洛托抽取＝T1；再用材料升級至 T2／T3（RO 附魔卷＋精煉感）。
2. **吃武器強化（+en）**：多數效果隨 `capWpnEn(武器.en)` 成長（安定後更香，鼓勵衝裝）。
3. **質變優先**：技能觸發／貫穿／滅魂等，而非純數值堆疊。
4. **AFK 安全**：單 proc 上限；同 id 不重複；武器最多 **2** 條；禁止三條同型高 proc。

### 為何武器上限 = 2（而非 3）

舊制 3 條時效果偏溫和。新池含 **技能 proc、+en 縮尺、追擊%、貫穿** 等較強質變；若仍允許 3 條，AFK 輸出曲線會爆。  
防具／飾品日後再開時可維持 3 條弱效果。巨靈屬性（gw）獨立，不佔附魔槽。

## 資料格式

```js
item.se = [
  { id: 'we_pierce', t: 1 },   // t = 1|2|3
  { id: 'we_drain',  t: 2 }
]
```

- 舊字串 id（`se_soulleech` 等）載入時 **遷移或清除**。
- 已移除池 id（`we_poison`／`we_skillfire`／`we_mut_*`）載入時清除。
- 防具 stub 仍可能以字串 id 存在（`se_thorns`…），戰鬥舊鉤保留。

**Proc 帽**：技能附咒 ≤ 9%；戰咒 ≤ 16%；追擊 ≤ 10%。同武器不可抽到兩條相同 id。武器槽 **最多 2**。

## UX（克洛托）

1. 選武器 → 顯示最多 2 槽（含階層 T1–T3）。
2. 空槽：**抽取**；已有：**改寫**／**升級**（材料不足灰掉）。
3. Tooltip：`✦ 席琳附魔（n/2）：名稱 T階 — 動態說明（含目前 +en 實效）`。
