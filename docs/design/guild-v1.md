# Idle Lineage 冒險者公會設計 v1（公會經營 × 後宮成員 × 頭目懸賞實戰）

> 草案 v1（2026-10-08）　基底：v3.8.116（關卡模式 Phase 1）　範圍：設計文件，**唔改遊戲程式碼**。
> 核心：玩家係「公會長」，收集返嚟嘅成年女性角色係「公會成員」。普通委託自動派遣、放置收益；**只有頭目懸賞先要玩家親自帶隊打即時戰鬥**。內容浪漫／曖昧，但唔會露骨。
> 用戶回饋：「關卡模式同以前差唔多」→ 本文件第 9 節重新定義戰鬥外觀（橫向即時 sprite 戰鬥），令打頭目有意義、有睇頭。

## 2. 成員非戰鬥特性

### 2.1 特性值（每項 0–100）

| 特性 | 影響 | 職業傾向（基礎值） |
|---|---|---|
| 探索 🧭 | 調查成功率、隱藏寶物 | 妖精 60、黑暗妖精 55、幻術士 40 |
| 交涉 💬 | 護送成功率、報酬 +% | 公主 70、幻術士 50、法師 40 |
| 採集 🌿 | 採集量 | 妖精 65、戰士 45、龍騎士 30 |
| 戰力 ⚔️ | 討伐成功率 | 由等級＋戰鬥值換算：`min(100, 等級×0.8 + (STR/DEX/INT 最高值)×0.2)`，150 上限沿用 |
| 魅力 ✨ | 名聲獲得、酒館招募 | 公主 75、黑暗妖精 50；同 CHA 掛鈎：`base + CHA×0.3` |
| 體力 ❤️ | 每日可出委託次數（3–6） | 騎士/戰士 6、法師/幻術士 4 |

- 特性來源：職業基礎值 + 好感度每級 +2 + 個人特長（抽卡角色固定 1 個「★特長」+15）。
- 存檔角色成員：特性由其真實六維計（沿用 `buildAlly` 讀到嘅 `d`）。

### 2.2 成功率公式

```
需求值 R = 委託等級需求（D20 / C40 / B60 / A80 / S100）
隊伍值 T = Σ(成員主特性 × 權重) / 人數 + 職業配合加成(5–15)
成功率 = clamp(50% + (T − R) × 1.5%, 5%, 95%)
大成功 = 成功率 × 20%（獎勵 ×2，名聲 ×2）
失敗：獎勵 25%，成員體力額外 −1，好感度 −0（唔扣，避免挫敗感）
```

| 例子 | 隊伍值 T | 需求 R | 成功率 |
|---|---|---|---|
| D 級採集，妖精 Lv30（採集 65） | 65 | 20 | 95% |
| B 級護送，公主 Lv45＋騎士 | 58 | 60 | 47% |
| A 級調查，3 人平均探索 70＋配合 10 | 80 | 80 | 50% |

### 2.3 報酬公式

```
金幣 = 基礎報酬(1.2 表) × (1 + 交涉×0.3%) × 時長倍率(1時1.0 / 4時3.2 / 8時5.8) × 公會加成
資源 = cbExpedRewards(地圖, 時長, 成員Lv, 公會Lv)   ← 沿用
經驗 = 成員等級需求 × 2% × 時長（只對存檔角色成員；沿用 getExpGainMult）
名聲 = 1.2 表 × 魅力加成(1 + 魅力×0.5%)
好感 = +1（每完成 1 張），大成功 +2
```

## 9. 關卡戰鬥形式（橫向即時 sprite 戰鬥，公主連結風）

### 9.1 戰場

| 項目 | 規格 |
|---|---|
| 視角 | 橫向側視，我方 5 人喺**左**、敵方喺**右** |
| 場景 | 背景用現有地圖圖（`assets/area/` 或地圖底圖），按委託地圖揀；地平線 60% 高 |
| 站位 | 我方前排 x=32–38%、後排 x=14–24%；敵方前排 x=62–68%、後排 x=76–86%；y 分 3 條線錯開 |
