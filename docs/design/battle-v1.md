## 1. 戰鬥流程

### 1.1 結構：關卡 = 3 波 + 頭目波

| 階段 | 內容 | 時間上限 | 失敗條件 |
|---|---|---|---|
| 第 1 波 | 3–5 隻雜兵（現有地圖怪池 `maybeSpawnMobs` 抽） | 共用 90 秒 | 全隊倒下 / 超時 |
| 第 2 波 | 3–5 隻，1 隻精英（HP×2，帶 1 個詞綴） | | |
| 第 3 波（頭目） | 1 頭目（＋0–2 小兵），沿用現有 boss 資料 | 頭目波另計 90 秒 | |

- 波與波之間 1.5 秒過場：**HP 保留**、能量保留 50%、MP 回 10%。
- 頭目登場時有「BOSS」橫額 + 頭目立繪（現有怪圖）。
- 勝利條件：頭目波清空。評分 ★1–3：★1 過關、★2 無人陣亡、★3 60 秒內過關。★3 過關後可「掃蕩」（直接領獎）。

### 1.2 時間軸：tick 制（唔係回合制）

| 項目 | 數值 | 來源 |
|---|---|---|
| 邏輯 tick | 100ms | `TICK_MS` 沿用 |
| 普攻間隔 | `aspd×10` ticks（約 0.6–1.5 秒） | `playerAttackIntervalTicks` 公式套落每個單位 |
| 技能（自動） | 各自冷卻 8–15 秒，冷卻好就自動放 | 新增 `unit.skillCd` |
| 奧義 | 能量滿 1000 先可放（第 4 節） | 新增 |
| 戰鬥速度 | ×1 / ×2 / ×4（×4 要 VIP 或通關後解鎖，暫定全部免費開） | 每次 gameLoop 跑 N 個 tick |

### 1.3 自動 vs 手動

| 模式 | 普攻 | 技能 | 奧義 |
|---|---|---|---|
| 手動（預設） | 自動 | 自動 | **玩家撳頭像先放**（能量滿時頭像發光） |
| 半自動 | 自動 | 自動 | 頭目波先自動，雜兵波保留能量 |
| 全自動 | 自動 | 自動 | 一滿就放 |

- 「保留能量」小技巧：手動模式下能量滿咗會停喺 1000，唔會浪費；對頭目先一次過放，即係手動嘅樂趣。
- 奧義放出時，戰鬥**暫停 0.8 秒**播 cut-in（第 4.3 節），暫停期間唔計時。

### 1.4 離線放置

- 沿用現有 fast-forward 補跑（`gameLoop` 嘅 catch-up）。離線時用「**模擬期望值**」，唔逐 tick 跑新戰鬥：
  - 以「最高已 ★3 關卡」嘅每分鐘收益（金幣/經驗/掉落）× 離線分鐘，上限 12 小時（可升到 24 小時）。
  - 返嚟時彈「放置收益」視窗，顯示時間、金幣、經驗、卡片、角色碎片。
- 現有野外狩獵（地圖掛機）**保留**，作為「傳統模式」；新戰鬥係「關卡模式」，兩者共用角色同裝備。

## 6. 傷害公式（沿用現有查表）

### 6.1 物理（近戰/遠程）

```
命中：d20 判定，沿用 getPhysicalDmg（hitValue = lv + 命中加成 − 敵lv + 敵AC 修正 → stretchHitValue）
基礎 = 武器骰 + 力量/敏捷傷害(getStrMeleeDmg / getDexRangedDmg) + 裝備額外傷害
倍率 = 技能倍率 × 爆擊(1.5 + 爆傷加成) × 屬性(5.3) × 羈絆 × 星級/突破(7)
減免 = × (1 − 敵DR%)，再 −敵固定 DR（沿用 raceDrMult 等）
最終 = max(1, floor(基礎 × 倍率 × 減免))
重擊(d20=20)：×1.5；擦傷(d20=19)：×0.5
```

### 6.2 魔法

```
coef = (1 − 屬性防禦 + 3 × SP / 32) × 階級倍率 × 世界事件/天氣/魔法塔倍率   ← magicDamageCoef 原樣
SP = INT SP（getIntExtraMp，INT150 = 60）＋ 道具 SP
傷害 = (法術骰 + getIntMagicDmg(INT)) × coef × 技能倍率 × MR 減免(mrMult)
```

### 6.3 範例數字（Lv50，★3，無屬性剋制）

| 項目 | 數值 STR/INT 100 | 數值 STR/INT 150 |
|---|---|---|
| 近戰額外傷害 `getStrMeleeDmg` | +57 | +88 |
| 近戰命中 `getStrMeleeHit` | +75 | +111 |
| 近戰爆擊 `getStrMeleeCrit` | 14% | 26% |
| 魔法傷害 `getIntMagicDmg` | +35 | +60 |
| 魔法命中 `getIntMagicHit` | +32 | +50 |

例 1：女戰士 STR 100，武器骰期望 12，技能「狂暴斬」180%：
`(12 + 57) × 1.8 = 124`；爆擊（14%）×1.5 = 186；敵 DR 10 → 約 114–176。

例 2：女法師 INT 150（SP 60）、流星雨 350%、法術骰期望 20：
`coef = 1 + 3×60/32 = 6.63`；`(20 + 60) × 6.63 × 3.5 ≈ 1856`（全體），敵 MR 50 減免後約 1100。

例 3：火屬性妖精打地屬性頭目：×1.25；雨天 火−10% → ×1.125。

> 平衡目標：Lv50 普通關頭目 HP ≈ 隊伍 30 秒 DPS；一次奧義 ≈ 頭目 HP 15–25%。

| 星級 ★1–★6 | 每星全屬性 +3（仍經 150 上限夾）、奧義倍率 +5% | `hero.star` |
| 突破（同角色碎片） | 等級上限 +10（最多 Lv100，對應轉生思路 `js/46`） | `hero.limitBreak` |
| 好感度 Lv1–10 | 每級 HP +1%、Lv5 解鎖第 2 張立繪、Lv10 解鎖專屬語音/cut-in | `hero.affection`；立繪由 `PORTRAIT_DB` 加 `heroId`、`unlockAff` 欄 |
| 裝備 | 沿用現有裝備系統，抽卡角色有自己 `eq` | 參考傭兵 `allyStrikeRoll` 結構 |

- **單一接口**：`battleUnitStats(unit)` → 回傳 `{str,dex,int,con,wis,cha,hp,mp,ac,mr,aspd,...}`；主角/傭兵直接用 `recomputeStats` 結果，抽卡角色用 `heroBaseStats × 稀有度 × 星級 + 裝備`。
- 好感度增加途徑：出戰、送禮（道具）、小遊戲（第 8.4 節）。
