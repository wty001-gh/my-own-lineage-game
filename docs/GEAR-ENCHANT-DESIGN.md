# 防具／飾品附魔設計（席琳・克洛托）

日期：2026-09-19（Asia/Taipei）・gearpool.20260919a／GAME_VERSION **v3.8.46**  
範圍：**防具／飾品**（武器池 `we_*` 不變）

## 設計原則

1. **先抽後升**：克洛托抽取＝T1；材料升級 T2／T3。
2. **分部位獨池**：每個 slot 只抽自己的 group；**頭盔唔再 ∪ 甲胄**；**斗篷獨立 CLOAK**。
3. **弱過武器**：非武器每件最多 **2** 條；proc／減傷刻意低於 `we_*`。
4. **吃裝備 +en**：多數效果隨強化輕微成長。
5. **最小共用**：幾乎每條 `ae_*` 只掛單一 group。
6. **主題**：甲胄＝生存；手套＝輔助 DPS；斗篷＝軟防／魔御；頭盔＝專注／技變。
