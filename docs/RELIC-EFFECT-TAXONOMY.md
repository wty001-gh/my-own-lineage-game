## B) 不建議轉成通用附魔

| 類型 | 原因 | 代表 |
|---|---|---|
| **奇古獸 qigu** | 整條攻擊改寫為必中魔傷路徑；綁幻術士／魔劍精通 | 鱷魚靈魂；曼陀羅之靈；夢幻蘑菇；幻夢火炎；阿茲特亡靈；迷你闇精靈 |
| **鎖鏈劍 chainsword + weakExpose** | 職業武器身份＋弱點層＋屠宰者互動 | 海星腕足；暗精靈鎖鏈劍；石化雞蛇；黑虎雙尾鞭；熔岩噴嘴；青炎；毒鵺黑尾等 |
| **屠宰變體 slaughterHits/Random** | 改寫屠宰者技能本身 | 凜冽青色火炎 |
| **骨刺 bonespike** | 連射疊層＋普攻引爆，綁弓流程 | 殘暴骸骨意志之弓 |
| **eff: crush / cleave / pierce 行為** | 重擊／切割／穿透是武器攻擊模型（含精通交互） | 大量雙手斧鎚、鐮刀、長槍 |
